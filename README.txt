Campus Resource Reservation System
Authors: 
  Robert Clark
  Wesley Jackson
  Tia Davis

System to manage campus resources, reservations, waiting lists, cancellations, and reports.

Resources are stored in structs which are then stored in a vector.
Reservations are stored in a doubly linked list.
Waiting lists are stored in a queue.
Cancellation history is stored in stack.

File Organization:
include/ has all header files.
src/ has all source files.
data/contains the input files.
